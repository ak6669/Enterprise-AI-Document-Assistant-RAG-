ENTERPRISE CLOUD ARCHITECTURE AND COMPLIANCE POLICY
Document Ref: POL-2026-CLOUD-01
Effective Date: January 15, 2026
Author: Global Infrastructure & Security Architecture Board

SECTION 1: EXECUTIVE MANDATE & CLOUD INFRASTRUCTURE
All production digital workloads must be containerized and hosted in Microsoft Azure Container Apps within the primary geographic region. Services must enforce zero-trust identity verification, mutual TLS 1.3 encryption, and role-based access control (RBAC). No services may expose unencrypted HTTP interfaces to public networks.

SECTION 2: RETRIEVAL-AUGMENTED GENERATION (RAG) COMPLIANCE
Enterprise RAG systems must implement strict grounding guardrails. Language models must not generate ungrounded assertions or hallucinate facts beyond the indexed document corpus.
Every factual claim presented to an end user must cite the originating document name and exact page number. Where page numbers are ambiguous, chunking algorithms must restrict segmentation to within known page boundaries.
Vector embeddings must utilize approved dense models such as Sentence Transformers (all-MiniLM-L6-v2) or BGE embeddings, and vector indices must be maintained in dedicated, isolated collections with cosine similarity metrics.

SECTION 3: RELATIONAL DATA RETENTION & POSTGRESQL AUDITING
All transactional document metadata, user query sessions, and citation attributions must be persisted in a PostgreSQL 16 relational database.
Audit logs must record document hash signatures (SHA-256), chunk identifiers, timestamp of ingestion, and processing latency.
Any document deletion request must atomically remove the physical file, relational records, and associated vector embeddings from the vector store.
